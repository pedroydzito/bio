# bio

Site estático de link-in-bio, publicado na Vercel no projeto `1pedrolima-links`.

Produção: https://bio.1pedrolima.com

## Como editar

Edite o HTML e o CSS (`index.html`, `styles.css` e, se precisar, `og.html`). Faça push para a branch `main` para publicar: a Vercel faz o deploy automaticamente a cada push nessa branch.
